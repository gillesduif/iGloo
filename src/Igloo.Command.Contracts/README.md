# Igloo.Command.Contracts

The typed V1 command contract of the iGloo CLI (`Igloo.Cli.exe`): capability descriptors, requests, results, progress and the stream events of the `invoke --machine` JSON Lines transport, plus the typed inputs and results of the public capabilities.

This package is licensed under Apache-2.0 so that any tool can speak the contract. The CLI and the engine behind it are GPL-3.0-or-later and live in [gillesduif/iGloo](https://github.com/gillesduif/iGloo); the JSON schemas are under `docs/spec/command-contract` there.
