# Beta Track

Beta means one thing for users: Debian, Linux Mint and Fedora KDE install unattended alongside a retained Windows 11 from the Community wizard, migrate the selected data, and do so again on a second attempt after a failed or aborted first one. Everything on this page serves that sentence. Work that does not (One mascot/chat/voice, Fleet server, the recovery-proof layer, CLI governance) is not blocked, but it does not gate beta and should not share a working tree with installer fixes.

This page is the beta checklist. The architecture convergence items in [[15 - Implementation/Master Implementation Checklist]] (AC-01…AC-12) are a separate, longer track and are **not** beta preconditions.

## Observed on 25 October 2026

The r5 Debian run in the disposable VirtualBox guest completed preparation (NTFS shrink 129,649 → 72,447 MiB, OEMDRV partition 6 at I:, preseed injected into initrd, shim/GRUB staged, full ISO and staging artefacts copied) and then failed in `RegisterBootEntry` with `BootPlanDeleteReferencesUnavailable` → `CommunityRecoveryBoundaryException (ScopeUnresolved)`. The planner refused because a leftover iGloo BCD object from an earlier run could not be proven deletable. Resolved by [ADR-014](../decisions/014-boot-registration-is-not-gated.md): registration is the v0.2-alpha NVRAM + bcdedit path again. Earlier in the same run, staging stopped once on `SQLite Error 5: database is locked` for Edge's `History` while Edge background processes were open; retry after closing them succeeded (3,690 files, 1.7 GB).

## Not on this list, on purpose

Exact recovery proofs for boot registration and storage (AC-06), `migration.prepare/execute/verify` as public CLI capabilities (AC-07/08), and the CLI process-gateway governance (AC-01/03) are valuable and stay on their own track. They are not what a beta tester needs to install Linux.
