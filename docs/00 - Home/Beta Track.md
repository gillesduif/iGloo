# Beta Track

Beta means one thing for users: Debian, Linux Mint and Fedora KDE install unattended alongside a retained Windows 11 from the Community wizard, migrate the selected data, and do so again on a second attempt after a failed or aborted first one. Everything on this page serves that sentence. Work that does not (One mascot/chat/voice, Fleet server, the recovery-proof layer, CLI governance) is not blocked, but it does not gate beta and should not share a working tree with installer fixes.

This page is the beta checklist. The architecture convergence items in [[15 - Implementation/Master Implementation Checklist]] (AC-01…AC-12) are a separate, longer track and are **not** beta preconditions.

## Observed on 25 October 2026

The r5 Debian run in the disposable VirtualBox guest completed preparation (NTFS shrink 129,649 → 72,447 MiB, OEMDRV partition 6 at I:, preseed injected into initrd, shim/GRUB staged, full ISO and staging artefacts copied) and then failed in `RegisterBootEntry` with `BootPlanDeleteReferencesUnavailable` → `CommunityRecoveryBoundaryException (ScopeUnresolved)`. The planner refused because a leftover iGloo BCD object from an earlier run could not be proven deletable. Resolved by [ADR-014](../decisions/014-boot-registration-is-not-gated.md): registration is the v0.2-alpha NVRAM + bcdedit path again. Earlier in the same run, staging stopped once on `SQLite Error 5: database is locked` for Edge's `History` while Edge background processes were open; retry after closing them succeeded (3,690 files, 1.7 GB).

## Observed on 11 November 2026

Host-only pass, no VM run: [[13 - Testing and Validation/Beta Baseline 2026-11-11]]. At `68670ad` the Release build was clean and the .NET suite had two failures on one stale assertion. A probe against that build showed the Debian and Mint seed copy creating the empty `files/` and `browser-profiles/` directory trees: with a nested folder `SeedIdentityWriter` threw `Selected user data contains an unbound empty directory` (in `Prepare` that is after the shrink); with a flat folder the seed kept an empty `files/Documents`, which the Debian-family agent prefers over the Windows volume. Fixed in `e881f5b`. The rows below carry an "11 Nov" note where something changed; every such note is source reading or unit tests, not installer evidence.

## Protected host (developer safety)

Not a beta condition. It exists because the install path was once started on the development machine instead of the VM. An administrator marks a machine with `HKLM\SOFTWARE\Policies\iGloo`, value `ProtectedHost` (integer, non-zero); iGloo only reads it. While the value is set, or cannot be read, every disk, boot and firmware write stops with `HostProtectedException` immediately before it would start: Windows shrink and extend, `diskpart`, WMI partition create, format and delete, UEFI variable writes, every `bcdedit` call except `/enum firmware`, the BCD WMI writer, ESP cleanup, `RealTimeIsUniversal`, seed file writes, the USB writer's raw handles and copies, BitLocker decryption and the two restarts. The wizard shows the notice above every step; the CLI prints it on stderr for human output and at the end of help, never in `--json` or the machine stream.

Evidence (`71053e9`, unit tests only): a refusal test per writing service for both states, and a source test that ties every raw write primitive under `src/` to the guard. Outside the marker by decision: the read-only ISO mount and the per-user AutoPlay value. Left as it is: the reviewed and recovery paths without a product caller report a refusal from their inner primitives as a failed mutation; their entry points refuse first where one existed. No further extension before beta.

The test assemblies pin the marker to "not protected", so the suite itself runs unguarded on a protected machine. `Tests_reach_a_real_write_primitive_only_inside_a_refusing_scope` therefore scans `tests/`: a firmware write, `RunDiskpart`, `RunBcdedit`, a raw `CreateFileW`, the default BCD writer, the USB writer and a resizer or removal service on the real storage reader may appear only inside a test that first sets a refusing scope, and only two files may unpin the marker at all. A temporary offending file made it fail. Its limit: `DirectInstallService` keeps `diskpart`, `bcdedit` and the firmware calls as statics, so the tests that build one with fakes rely on its early refusals, which a source scan cannot prove.

## After beta

Each item was checked against the beta sentence (install, migrate, again after a failed or aborted attempt) and serves none of the three.

- **System Check reclaim becomes a question.** Automatic only for free space that exactly matches a seed iGloo made. `Prepare` does not depend on the reclaim: it measures the free extent itself and replaces a stale seed (B-01).
- **#220, locale fallback.** The agent never writes a locale the distribution lacks: when `ll_CC` is missing, `LANG` and `LC_TIME` take the same language (`en_GB.UTF-8` for `en`) and the formats the same country (`nl_BE.UTF-8` for `BE`). Moved here by decision; read in source it does not stop a Debian install, Mint and Fedora are not verified, and the r6 runs record `locale` after first boot.
- **AutoPlay and ISO mount.** Restore the AutoPlay value after a crash, and stop dismounting an ISO mount iGloo did not make.
- **Host protection.** Further guard coverage and a notice in the typed CLI streams.
- **Deferred partitioning work.** #227 (Debian's own ESP), exact-extent mode for the Debian hook (it requires a Linux ESP partition GUID, which the Community path does not supply) and the rest of M13 (#159, #161–#165).

## Not on this list, on purpose

Exact recovery proofs for boot registration and storage (AC-06), `migration.prepare/execute/verify` as public CLI capabilities (AC-07/08), and the CLI process-gateway governance (AC-01/03) are valuable and stay on their own track. They are not what a beta tester needs to install Linux.
