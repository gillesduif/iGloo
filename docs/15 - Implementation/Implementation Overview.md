# Implementation Overview

[[15 - Implementation/Master Implementation Checklist]] is the single canonical checkbox list for the proposed CLI/Core convergence tasks. [[02 - Architecture/Architecture Convergence Plan]] supplies safety order and acceptance criteria; [[00 - Home/Architecture Drift Register]] supplies the unresolved source conflicts. These AC tasks are not a new official release phase. [ROADMAP](https://github.com/gillesduif/iGloo/blob/main/ROADMAP.md), GitHub milestones and existing distro/Fleet issue records retain their original planning authority.

The immediate work is architecture governance and bounded process parity, then exact layout/artifact/state identity, secret custody, approval, recovery proof and durable operation ownership. Only after that can public prepare/execute/verify be considered. Community Host removal and Fleet Agent adapter removal are follow-on parity work. [[13 - Testing and Validation/Test Matrix]] states what a credible completion record needs; [[17 - Risks and Issues/Risk Register]] identifies likely failure impact.
